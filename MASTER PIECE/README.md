# ORBIT — النسخة المتكاملة

## التشغيل
1. فك ضغط المجلد كاملًا، ولا تنقل ملفات الصفحات منفردة.
2. افتح المجلد في VS Code وشغّل `index.html` بواسطة Live Server (localhost أو HTTPS).
3. صفحة البداية ثم تسجيل الدخول، أو إنشاء حساب طالب / معلم / مدرسة.
4. كل صفحة داخل مجلد مستقل: ملف HTML وCSS وJavaScript بنفس اسم الصفحة. الملفات المشتركة داخل `shared`.

حسابات للتجربة:
- student@orbit.com / Student123!
- teacher@orbit.com / Teacher123!
- school@orbit.com / School123!

## ما يعمل
- دخول وتسجيل محلي لكل الأدوار، مع رفض البريد المكرر وتخزين مشتق PBKDF2 مملّح بدل كلمة المرور الصريحة. حسابات التجربة ثابتة في المصدر.
- بيانات الطالب وصورته وتقدمه مرتبطة ببريده، وتفضيلات اللغة والمظهر مشتركة. الصور والمرفقات في IndexedDB.
- سايد بار ثابت وموحد، رجوع، خروج، قائمة موبايل، حماية الصفحات حسب الدور، RTL/LTR وDark/Light ومدار/هادئ.
- ملف الطالب: صورة مع معاينة، اسم، بريد، عنوان، مستوى، حفظ وإلغاء.
- تعلمي: موضوع ومادة ومستوى، شروحات فيزياء مراجعة محليًا للقوى والطاقة والموجات والدوائر. أسئلة تختلف حسب المستوى، اكتشاف الخطأ، ومؤشر تقدم محفوظ.
- فيديوهات الدروس تأتي من منشورات المعلمين المرتبطة بالموضوع؛ القنوات الخاصة تحتاج عضوية. لا يوجد مزود بحث فيديو خارجي مفعل.
- التبادل للطالب: كتب وأدوات ومعدات، بيع أو إعارة، كمية وموقع وحالة وصور، تعديل وحذف المالك، تفاصيل وطلبات محفوظة محليًا. لا يوجد دفع إلكتروني أو إرسال رسائل خارجي أو مشاركة بين أجهزة.
- القنوات: البحث والانضمام برمز؛ لا تظهر قناة تلقائيًا ضمن قنوات الطالب. نشر مرفقات وفيديو وPDF وصور وتعديل وحذف المعلم لمنشوراته.
- المختبر وتجارب السيارة والبندول والنابض والمقذوفات وحركة العنوان محفوظة.
- إنشاء الدرس أول خيار للمعلم. تحضير يدوي قابل للتعديل والطباعة إلى PDF؛ توليد AI وWord يتطلبان الخادم.
- توظيف المدارس: فرص ومطابقة قواعد قابلة للتفسير، موافقة اكتشاف الملف، تقديم وإدارة الحالة وإشعارات محلية.

## ربط AI
عدّل `shared/config.js` وأضف `learningEndpoint` لعنوان خادمك.
طلب POST مع cookie وJSON:
`{ "topic": "Fractions", "subject": "math", "level": "secondary" }`
الاستجابة:
```json
{
  "explanation": "شرح مناسب للمستوى",
  "simpleExplanation": "شرح بديل أبسط",
  "videos": [{ "title": "عنوان فيديو", "url": "https://..." }],
  "questions": [{ "question": "السؤال", "answer": 4, "explanation": "خطوات الحل" }],
  "activities": ["نشاط عملي مناسب وآمن"]
}
```
تدعم الإجابة رقمًا أو نصًا. الواجهة تعرض الشرح والفيديوهات والأسئلة والتغذية الراجعة والأنشطة والتقدم، وتعالج الأخطاء دون ادعاء نجاح. مصدر الفيديو ومراجعة صلاحية المحتوى مسؤولية الخادم. دون endpoint، المتاح هو المحتوى المراجع محليًا والبحث في دروس المعلمين فقط. تحليل صور الأسئلة غير موصول.
ضع مفاتيح مزود AI على الخادم فقط. نفذ التحقق من الجلسة والصلاحيات والحدود ومراجعة المحتوى على الخادم.

## ربط Google
أضف `googleClientId` و`googleSessionEndpoint` في `shared/config.js`.
- Web OAuth client مع authorized JavaScript origins لـlocalhost أو نطاق HTTPS.
- تستخدم الواجهة مكتبة Google Identity Services الرسمية.
- ترسل POST `{ "credential": "ID_TOKEN" }` إلى endpoint الخاص بك.
- الخادم يتحقق من توقيع ID token وissuer وaudience وexpiry ويصدر جلسة آمنة، ثم يرجع `{ "user": { "name": "...", "email": "...", "role": "student" } }`.
- يحدد الخادم دور المستخدم المسجل أو يستكمل تسجيله. لا تثق بدور يرسله المتصفح.
- بدون الإعداد يبقى زر Google معطلًا ورسالة واضحة؛ لا يوجد نجاح تجريبي.
الوثائق الرسمية:
https://developers.google.com/identity/gsi/web/guides/get-google-api-clientid
https://developers.google.com/identity/gsi/web/guides/verify-google-id-token

## حدود النسخة
هذه واجهة HTML/CSS/JS تعمل ببيانات المتصفح. التسجيل المحلي وحماية الواجهة لا يشكلان نظام مصادقة إنتاجيًا؛ تعديل التخزين ممكن للمستخدم. لا توجد قاعدة بيانات خادم، جلسات خادم أو مشاركة حقيقية بين الأجهزة. يلزم backend للمصادقة الإنتاجية، AI، Google، نقل الطلبات والمرفقات والإشعارات بين المستخدمين، والدفع. لا تستخدم بيانات حساسة في التجربة.
لا تمسح بيانات المتصفح إن أردت الاحتفاظ بالملفات. احتفظ بنفس عنوان localhost والمنفذ، لأن التخزين مرتبط بالأصل.

## التحقق
تم التحقق عبر Edge من التسجيل والدخول، الحسابات المنفصلة، الصفحات والروابط، ثبات السايد بار، الموبايل، ملف الطالب والصورة والإلغاء، التبادل والطلبات، تقدم التعلم وإجابات الأسئلة، غياب تكامل Google، وعقد AI باستجابة اختبارية محلية. كذلك أُعيد فحص تدفق توظيف المدارس وصلاحياته. لا تعني استجابة AI الاختبارية وجود مزود AI حقيقي موصول.

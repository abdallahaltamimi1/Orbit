# Campus asset provenance

`campus-preview.png` is a 1120 × 700 capture of the actual original WebGL campus implemented in `school-tour/campus.js` and `tour-scene.js`. Capture harness: `work/school-tour-preview.cjs` in the Codex task workspace. Origin metadata is embedded in PNG tEXt and verified by Impeccable's asset scan (one raster, zero missing).

The campus geometry, furniture, landscape and procedural canvas textures are original project code. No downloaded campus model, stock photograph, scanned real school, AI image, GLB, HDR or third-party texture was used. It is an illustrative school, not a representation of a specific school. Existing project Three.js supplies rendering and retains its upstream license; no new dependencies were installed.

Fallback campus plan is an original geometric SVG diagram. It is an accessibility/loading fallback, not a substitute sold as photorealistic imagery.

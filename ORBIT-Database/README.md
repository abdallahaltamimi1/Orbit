# ORBIT Database

ORBIT is an educational management platform that connects schools, teachers, and students in one integrated digital environment.

## 🌐 Live Demo

**[Visit ORBIT Website](https://keen-tartufo-97591b.netlify.app/)**

## 📌 Database Overview

The ORBIT database is built using **Microsoft SQL Server** to manage academic operations, users, educational activities, and teacher recruitment.

## ⚙️ Database Features

- Academic year management
- Student and teacher records
- Classes and sections
- Teacher assignments and timetables
- Educational channels and assignments
- Recruitment and interviews
- Academic monitoring
- Student promotions

## 🛠️ Technologies

- Microsoft SQL Server
- T-SQL
- Markdown Documentation

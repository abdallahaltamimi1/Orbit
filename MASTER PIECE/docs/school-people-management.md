# Teacher directory and school subject catalogue

Completed 4 November 2026. Frontend-only; existing browser stores and IDs retained.

Teachers now has one name/email search, Add Teacher, and fully clickable keyboard-accessible teacher rows. Teacher Details is a native modal side drawer on desktop and fills the viewport on mobile. It contains selected-year assignments grouped by subject/grade with section badges, editing, explicit identity review, one-time issuance for existing records without accounts, safeguarded removal, and audit history. Multi-section annual and reviewed legacy assignment edits validate the entire batch before a single store write. Removed annual assignments become retained audit tombstones rather than losing history; all existing raw-store consumers continue seeing only current assignments. Linked timetables, channels and academic references prevent unsafe changes/removal. Archived years remain read-only.

Creation asks only full name and school email, preserves the existing duplicate-email/explicit identity-review rules, and reuses temporary password hashing/mandatory first-login changes. A one-time receipt and Open teacher details action follow creation. Shared ORBIT account email remains identity-managed: school record name is editable, while an existing canonical account email is displayed read-only and identity links require explicit review. Personal accounts are never deleted by removing a school teacher.

Subjects now lists only adopted school subjects, with edit and deactivate actions. Add Subjects offers 13 categorized bilingual suggestions and custom subjects, supports multi-select, and writes only explicit selections in one atomic academic-store update. Canonical Arabic/English aliases prevent duplicate adoption and renaming conflicts. Inactive subjects are unavailable for new assignments/channels; existing assignment references and authorized school-channel access are preserved. Subjects are school-wide, independent of selected-year lifecycle. No destructive subject deletion is exposed.

Removed duplicated assignment tables and the separate Teacher Assignments sidebar destination. Existing `section=subjects&teacher=<id>` and `section=subjects#teaching-assignments` links route to Teachers, preserving the selected academic context; teacher-specific links open the correct details drawer. Existing assignment services and legacy data have not been deleted or migrated.
